About Me

I live in Mira, a quiet Portuguese village between Aveiro and Coimbra, where I appreciate the balance between ambition and a grounded way of life.

Personal Project: Self-Hosted Homelab Infrastructure

Ongoing personal infrastructure project built on a single refurbished mini PC, run as a small production environment rather than a lab toy. A Proxmox VE hypervisor hosts VMs and LXC containers across a network segmented into four zones with 802.1Q VLANs, trunked over a single physical link and mediated by a dedicated OPNsense firewall VM with a default-deny policy between zones. Storage runs on TrueNAS SCALE with ZFS, exported over NFS and SMB; services (Nextcloud, Jellyfin, Caddy) run in Docker Compose inside LXC containers, with WireGuard as the only entry point from the internet. Backups run nightly via rsync to an external SSD and were validated by an actual restore, checked at three levels: structural comparison of file listings, checksum verification, and playing back a restored video file. Base services are complete and validated; the VLAN segmentation is built and service migration is in progress. Every incident along the way has a written post-mortem covering symptom, diagnosis path, root cause and fix, including the wrong turns, because the wrong turn is usually the useful part.

Final-Year Project (LEI-PROJ): XAI Energy Chatbot

Final-year internship project developed at GECAD (ISEP's Research Group on Intelligent Engineering and Computing for Advanced Innovation and Development), tackling the interpretability gap in machine learning-based energy forecasting: the predictions, metrics and explanations these models produce are often too technical for users without specialized knowledge. The project delivers the XAI Energy Chatbot, an LLM-based conversational system that lets users query, in natural language, GECAD's energy consumption/generation forecasting models and their explainability artifacts (SHAP, LIME, PDP, ALE, Anchors, Counterfactuals), with responses adapted to the user's technical profile. Built on Clean Architecture, the backend is the sole orchestrator of a planner → validator → executor → responder tool pipeline, coordinating a locally-hosted LLM (LM Studio), a Retrieval-Augmented Generation layer over validated documentation (Qdrant), and the external ForeXAI explainability/forecasting API, backed by PostgreSQL persistence and LDAP/local composite authentication. The solution also ships an administrative area for user management, RAG corpus curation and ForeXAI diagnostics, and was validated with unit, integration and end-to-end (Playwright) test suites plus a CI pipeline.

ANADI Project: Predicting Distribution Transformer Station Utilization with Machine Learning

Group project (with Miguel Lopes) for the Data Analysis (ANADI) course, applying supervised machine learning to 72,027 Distribution Transformer Stations (PTDs) from Portugal's electrical distribution grid operator, E-Redes. The work builds on an earlier exploratory data-analysis assignment from the same course and addresses two complementary tasks: regression, to predict the available capacity margin in kVA (PFolga_PTD); and classification, to categorize each PTD into one of three utilization levels (low, medium, high). Five algorithms (Linear Regression, Decision Trees, SVM/SVR, k-Nearest Neighbors and Neural Networks) were evaluated per task using cross-validation (stratified k-fold for classification, k=5) and hyperparameter tuning via GridSearchCV. The Neural Network achieved the best result in both tasks (R²=0.4784 on regression, F1-score macro=0.6669 on classification), with statistical significance confirmed through paired t-tests and the Wilcoxon test. Findings are documented in an IEEE-format scientific article, covering exploratory data analysis, methodology, hyperparameter optimization and statistical validation of results.

Integrative Project: Sustainable Port Logistics Management

Integrative project developed during the 5th semester of the Computer Engineering degree, simulating a Request for Proposal (RFP) from a port management company for a new-generation, sustainable and intelligent port logistics system. The prototype covers vessel visit notifications and approval, dock assignment, cargo manifests, and resource/task scheduling, with intelligent planning support (including a genetic algorithm) implemented in Prolog. The system is split into decoupled .NET Web APIs following Clean Architecture and Domain-Driven Design (port operations and planning/scheduling), a Node.js authentication service backed by MongoDB and Keycloak (OAuth2/OIDC) for identity management, and an Angular single-page application with a Three.js-based 3D visualization of vessel positions, containers, and resource allocation. The project integrates concepts from Systems Administration (ASIST), Systems Architecture (ARQSI), Management (GESTA), Artificial Intelligence (IART), Laboratory and Project V (LAPR5), and Graphic Systems and Interaction (SGRAI), and was developed over three SCRUM sprints with CI/CD pipelines deploying to Azure virtual machines.

Study of the algorithms of the Euler method and the 4th order Runge-Kutta method

The objective of this project is to develop a Java application that models the epidemic consumption of drugs using a system of first-order ordinary differential equations (ODEs). The SIR model (Susceptible, Infected, Recovered) was used to represent the dynamics of drug consumption within a population. Numerical methods, specifically the Euler and 4th order Runge-Kutta methods, were employed to solve the ODEs. Finally, a comparison of the results obtained from both methods was conducted.
