Project Software Sem 4 · 2024/25

Integrative Project: Drone Light Show Management

Project developed during the 4th semester of the Computer Engineering degree, focused on the creation of an integrated platform to manage drone light shows. The system supports features such as drone fleet registration, flight formation configuration, customer request management, show proposal generation, DSL-based script validation, and real-time drone simulation. The backend communicates with a remote database server via TCP sockets, applying Domain-Driven Design (DDD) principles and using Object-Relational Mapping (ORM) for persistence. The project integrates concepts from Computer Networks (RCOMP), Computer Systems (SCOMP), Application Engineering (EAPLI), and Programming Languages (LPROG), using Java, SQL, C, POSIX threads, shared memory, and ANTLR4 to build a robust, modular, and extensible system.

Project Software Sem 3 · 2024/25

Integrative Project: Industrial Production Management

Integrative project developed during the 3rd semester of the Computer Engineering degree, focused on designing and implementing a software solution for managing production in project-oriented and short-run industrial facilities. The application was built iteratively across three sprints and includes product and operations modeling (BOM and BOO), production simulation, machine control with sensor integration, production order planning, and a relational database built in PL/SQL. The solution integrates multiple technologies and paradigms, including Java, C/Assembly, and SQL, and covers key areas such as Computer Architecture (ARQCP), Databases (BDDAD), Information Structures (ESINF), Applied Physics (FSIAP), and Object-Oriented Development. The project follows agile SCRUM methodology (LAPR3) and Test-Driven Development (TDD) best practices.

Project Software LAPR1 · 2023/24

Study of the algorithms of the Euler method and the 4th order Runge-Kutta method

The objective of this project is to develop a Java application that models the epidemic consumption of drugs using a system of first-order ordinary differential equations (ODEs). The SIR model (Susceptible, Infected, Recovered) was used to represent the dynamics of drug consumption within a population. Numerical methods, specifically the Euler and 4th order Runge-Kutta methods, were employed to solve the ODEs. Finally, a comparison of the results obtained from both methods was conducted.
